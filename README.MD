## Требования
Для корректной работы мода у вас должны быть установлены:
- [SMAPI](smapi.io) (актуальная версия для Stardew Valley 1.6)
- [Content Patcher](https://www.nexusmods.com/stardewvalley/mods/1915)
- [SpaceCore](https://www.nexusmods.com/stardewvalley/mods/1348)

---

## Установка
1. Скачайте последнюю версию мода со страницы релизов (или Nexus Mods).
2. Распакуйте архив в папку `Stardew Valley/mods`. 
   * *Убедитесь, что папка `[SMAPI] Soldat` находится внутри основной папки мода.*
3. Запускайте игру через SMAPI.
