# SoldatAuction

Новый отдельный SMAPI-мод для Stardew Valley 1.6. Создан как стартовый проект для VS Code.

## Требования
- .NET SDK 6.0
- SMAPI для Stardew Valley 1.6
- Путь к установленной игре задаётся через переменную `GamePath` при сборке (см. ниже).

## Открытие в VS Code
1. Распакуй архив.
2. Открой папку `SoldatAuction` в VS Code.
3. В `SoldatAuction.csproj` проверь путь к Stardew Valley API. По умолчанию используется `$(GamePath)`.
4. Открой терминал в папке проекта и выполни:

```powershell
dotnet build -p:GamePath="D:\SteamLibrary\steamapps\common\Stardew Valley"
```

Замени путь на фактическую папку игры. В ней должен быть `Stardew Valley.dll`.

## Установка
После сборки скопируй папку `bin/Debug/net6.0/SoldatAuction` (включая `manifest.json` и DLL) в папку `Stardew Valley/Mods/`.

Если файлы мода не копируются автоматически, скопируй `manifest.json` в папку сборки вручную.

## Тестовый запуск
Запусти игру, загрузи сохранение и введи в SMAPI-консоль:

`soldatauction_test`

Это пока тестовый запуск логики через внутриигровые вопросы. Подключение к событию Content Patcher `James.6h.1p` сделаем следующим этапом.

## Важные заметки
- Металлическая рука пока является визуальным лотом на столе: мод не создаёт предмет в инвентаре.
- Текущая версия — каркас первого этапа. Перед подключением к основному событию нужно уточнить стартовую ставку и поведение, если 40% исходного бюджета меньше 50 000 золота.
